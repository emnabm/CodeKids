- `welcome_astronaut_rocket.png` — Welcome screen hero illustration (astronaut kid riding a rocket among planets & stars)
- `mascot_astronaut.png` — Kid astronaut character shown on Create Account, Map, and Profile fallback
- `mascot_robot.png` — Helper robot mascot shown on Explanation panels

- `planet_blue.png` — Decorative cratered blue planet for Map / Auth backgrounds
